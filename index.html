2.1Projetos Acadêmicos (API)

Radar Cidadão

API 1 · 2026/1

Parceiro: Prof. Fernando Masanori Ashikaga (Fatec SJC) · Mar – Mai 2026 · Equipe Lumina · Dev Team

Problema resolvido

Em ano de eleição para Deputado Federal, eleitores, professores e jornalistas precisam avaliar o desempenho de deputados candidatos à reeleição e compará-lo à média nacional. Os dados de presença, gastos e atividades são públicos, mas técnicos, dispersos e difíceis de interpretar, o que dificulta decisões de voto e o ensino de cidadania com base em fatos neutros.

Solução desenvolvida

Aplicação web que consome a API pública de dados abertos da Câmara dos Deputados e traduz os dados em informação clara: página de deputados com fotos, busca por nome e filtro por estado; gráficos de gastos e presença com legendas explicativas; palavras-chave mais frequentes nos discursos; resumo em linguagem simples com nota de desempenho; indicação das fontes; tabelas roláveis no celular e página de erro para deputado inexistente.

Contribuições pessoais

  • Desenvolvedor da equipe nas três sprints, implementando e integrando funcionalidades do backlog.
  • Participação nas cerimônias Scrum e nas validações de entrega com o parceiro.
  • Versionamento com branches e padrão de commits.

Tecnologias utilizadas

PythonFlaskMariaDBDockerHTML5CSS3JavaScriptTailwind CSSGoogle ColabFigmaJira

Hard skills adquiridas

  • Desenvolvimento web com Python e Flask.
  • Consumo e tratamento de API REST pública.
  • Banco de dados relacional (MariaDB).
  • Análise exploratória de dados em notebooks.
  • Containerização com Docker e Docker Compose.
  • Prototipação de interfaces no Figma.

Soft skills exercitadas

  • Trabalho em equipe em um grupo de 9 pessoas.
  • Comunicação com cliente real e tradução de requisitos.
  • Organização por prazos de sprint (Scrum).
  • Comunicar dados complexos a públicos não técnicos.

SGOS — Sistema de Gestão de Ordens de Serviço

API 2 · 2026/2

Parceiro: ALTAVE · Set – Nov 2026 · Equipe GesTec · Scrum Master

Problema resolvido

A ALTAVE precisava monitorar, organizar e controlar o atendimento de solicitações operacionais e projetos de implantação que eram acompanhados de forma descentralizada, sem padronização das etapas entre departamentos e sem previsibilidade sobre os prazos de SLA contratual, o que gerava gargalos e dificultava a rastreabilidade do que foi feito, por quem e quando.

Solução desenvolvida

Sistema web com autenticação por perfil (Gestor, Analista e Técnico), projetos como agrupadores centrais de ordens de serviço por departamento, controle rígido de status com parecer técnico, cálculo automático de SLA com alertas de risco, anexos de até 50 MB, notificações in-app e por e-mail, registro de horas, relatórios em PDF, logs de auditoria e documentação interativa da API via Swagger.

Contribuições pessoais

  • Scrum Master: facilitação das cerimônias, acompanhamento das sprints e remoção de impedimentos.
  • Apoio à organização do backlog e à documentação de cada sprint.
  • Alinhamento do time com o Product Owner e o parceiro.

Tecnologias utilizadas

ReactTypeScriptNode.jsExpressPostgreSQLSupabasePrisma ORMJWTbcryptSwagger / OpenAPICucumber (BDD)

Hard skills adquiridas

  • API REST em Node.js/TypeScript com arquitetura em camadas (controllers, services, repositories).
  • Modelagem e migrations com Prisma e PostgreSQL.
  • Autenticação e controle de acesso com JWT.
  • Testes de comportamento (BDD) com Cucumber.
  • Documentação de API com OpenAPI 3.0.
  • Fluxo de trabalho Git com branches, DoR/DoD e padrão de commits.

Soft skills exercitadas

  • Liderança facilitadora e condução de cerimônias ágeis.
  • Comunicação com parceiro e equipe de 8 pessoas.
  • Gestão de tempo, prazos e prioridades.
  • Mediação de conflitos e colaboração.
