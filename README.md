# Portfólio Acadêmico — Cid Daniel Neves D'Oliveira

Portfólio digital do curso de Desenvolvimento de Software Multiplataforma (FATEC São José dos Campos), publicado com **GitHub Pages**.

## Estrutura
```
index.html            # página única (raiz = exigência do GitHub Pages)
assets/css/style.css  # estilos
assets/js/main.js     # menu mobile e navegação ativa
assets/img/           # fotos e imagens
assets/video/         # demonstrações dos projetos
```

## Publicação
1. Suba tudo na raiz do repositório (branch `main`).
2. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. O site ficará em `https://<usuario>.github.io/<repositorio>/`.

Tecnologias: HTML5, Tailwind CSS (CDN) e JavaScript puro — sem etapa de build.
